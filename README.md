## Deploy on Vercel

1. Import **Angeluis001/grayfoner-builders** at [vercel.com/new](https://vercel.com/new)
2. Framework: **Other**
3. Leave Build / Output / Install empty
4. Deploy
5. Add custom domain `grayfonerbuilders.com.au` when ready

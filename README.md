# Grayfoner Builders

Brisbane family-run construction company website — recovered from the [Internet Archive](https://web.archive.org/web/20260115110835/https://www.grayfonerbuilders.com.au/) and rebuilt as a static site for **Vercel**.

## Contents

- **Home** — About, Services, Portfolio, Testimonials, Contact  
- **Portfolio pages** — New Homes, Extensions & Renovations, Patios & Decks, Retaining Walls, Stables / Arena Roof  
- Contact: phone `0421 852 363`, email `admin@grayfonerbuilders.com.au`

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy on Vercel

1. Import this GitHub repository in [Vercel](https://vercel.com/new).
2. Framework preset: **Other** (static).
3. Build command: leave empty. Output directory: leave empty (root).
4. Deploy, then optionally attach `grayfonerbuilders.com.au` as a custom domain.
